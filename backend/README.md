# 정산 노트 백엔드 (구글 시트 + Apps Script)

`ledger.html`(정산 탭)은 정적 페이지라 데이터를 직접 저장할 수 없다. 여행 구글 시트에 붙인 Apps Script 웹 앱이 저장소 역할을 한다. 무료, 계정 추가 없음, 데이터는 내 시트에 남는다.

## 설치 (한 번만, 시트 주인이)

1. 여행 구글 시트 열기 → 상단 메뉴 **확장 프로그램 → Apps Script**
2. 열린 편집기의 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 전체를 붙여넣기
3. 맨 위 `const PIN = '1024'` 를 원하는 숫자로 바꾸기 (친구에게 알려줄 공용 비밀번호) → 저장(⌘S)
4. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(톱니) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 계정 선택 → "확인되지 않은 앱" 경고가 나오면 *고급 → (프로젝트명)(으)로 이동* → 허용
5. 표시되는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사
6. `ledger.html` 의 `const API_URL = '';` 에 그 주소를 넣고 커밋·푸시

## 확인

브라우저에서 `웹앱URL?action=ping` 을 열면 `{"ok":true,...}` 가 보이면 정상.

## 코드를 고쳤을 때

Apps Script 편집기에서 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. 새 배포를 만들면 URL이 바뀌니 "배포 관리"로 갱신할 것.

## 데이터

시트에 `_settings` `_expenses` `_transfers` `_checks` 탭이 자동 생성된다. 열은 `id | updated | summary | json`. 시트에서 직접 고칠 때는 `json` 열만 유효하다(summary는 보기용).
